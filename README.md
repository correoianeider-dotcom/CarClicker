##  CarClicker

Aplicación web desarrollada con Js, HTML y CSS siguiendo el patrón arquitectónico MVC (Modelo - Vista - Controlador).

##  Descripción

CarClicker es una aplicación interactiva que permite visualizar diferentes vehículos y contar la cantidad de clics realizados sobre cada uno de ellos.

El usuario puede seleccionar un automóvil de la lista y ver su imagen junto con un contador que aumenta cada vez que se hace clic sobre el vehículo.

##  Arquitectura MVC

- Modelo (Model): Gestiona los datos de los vehículos y el contador de clics.
- Vista (View): Se encarga de mostrar la interfaz gráfica (imagen, lista de autos, contador).
- Controlador (Controller): Controla la interacción entre el modelo y la vista.
